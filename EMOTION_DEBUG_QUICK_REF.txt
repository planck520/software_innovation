⚠️ 常见问题
─────────────────────────────────────────────────────────────────
问题1: 看不到任何日志
→ 摄像头未初始化或循环未启动，检查权限

问题2: "❌ API 返回 null"
→ 网络问题或未检测到人脸，检查光线和角度

问题3: "❌ 发生错误"
→ 网络连接问题，检查 WiFi 或移动网络

问题4: 日志正常但UI不更新
→ 热重启应用 (按 R 键)
